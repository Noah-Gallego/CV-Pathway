# CV Pathway Research: Air Pollution and Preterm Births in California

## Overview
This research analyzes the relationship between air pollution and birth outcomes across California counties from 2007-2023. The study examines how PM2.5 pollution levels correlate with preterm birth rates, comparing high pollution areas (Central Valley) with coastal counties.

## Key Findings
- **PM2.5 vs Preterm Births**: r = 0.286 (p < 0.001)
- **High pollution counties**: 12.9 μg/m³ PM2.5, 9.14% preterm births
- **Coastal counties**: 7.8 μg/m³ PM2.5, 7.98% preterm births
- **Impact**: +5.1 μg/m³ PM2.5 = +1.16% more preterm births

## Files
- `final.py` - Analysis script generating two key visualizations
- `data/` - California county data and preterm birth records
- `outputs/` - Generated charts and visualizations
